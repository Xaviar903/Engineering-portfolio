# Brainstorming Ideas
## Recycling machine Ideas
We're going to make a machine that first shreds the plastic, then makes it into pellets, and then finally melt it into the final shape.
We will have the shredder shred the plastic into pellets
We are then going to use an archimedes screw to push the pellets forward while melting the pellets using Ceramic heating ring elements.
We can clean by taking apart the Archimedes screw and cleaning it using water.
We could drop the pellets into an oven-like heating place to then funnel it into the mold/final shape.
We could clean it with water jets that only need to be pressed down with a foot that will automatically clean the area.

## Collection/sorting Ideas
We will collect by going around the school and collect the plastic from rooms and places.
When we bring them we will sort what plastic we are going to melt and what our machine cant melt and process.
We will throw away the plastic we can use into a recycling bin to send off with the rest of the schools.
We can use a wheelbarrow or another type of small/medium sized wagon that we can use to put the plastic in.
